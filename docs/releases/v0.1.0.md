## metron v0.1.0

First release of metron: a lightweight, harness-agnostic AI agent observability and evaluation CLI.

metron listens for the OpenTelemetry traces your agent already emits and keeps them in a single SQLite file in your project. There is no account, no server and nothing to host.

### What's in it

- `metron serve --tag v1` listens for OTLP traces over HTTP and gRPC on the standard ports and records them under a tag.
- `metron ls` lists what was recorded, grouped by tag.
- `metron show [tag or session]` shows the model calls and tool calls of a run as a timeline.
- `metron compare <a> <b>` compares two tags or sessions on duration, errors, calls and tokens.
- `metron completion <shell>` generates shell tab-completion.
- Model, token counts and span kind are read from the standard OpenTelemetry GenAI attributes.

### Install

```bash
go install github.com/gian-gg/metron@v0.1.0
```

Or download the archive for your platform below. Verify it against `checksums.txt` with `sha256sum -c checksums.txt --ignore-missing`.

### Good to know

- This is early software. The command line and the database schema may change between 0.x releases.
- Tokens are reported; cost is not.
- `compare` is only as meaningful as the number of traces behind it. The `traces` row shows how many each side has.
- The listener has no authentication. It binds to `127.0.0.1` by default; `--listen 0.0.0.0` exposes it to your network.
